# Issue tracker

- **Tracker:** GitHub Issues
- **Repository:** `sergeloie/peshki` (remote `origin`)
- **Triage label:** `ready-for-agent`
- **Workflow:** one issue → one branch → one pull request that closes the issue
- **Spec:** issue #1 (HTML5 version for Yandex Games)
- **Blocking edges:** written as text lines in each issue body (`Blocked by: #N`), because the
  repository does not use GitHub sub-issues.

Local-only scratch specs and tickets, when the network is unavailable, go to `.scratch/<feature>/`
and are never committed.

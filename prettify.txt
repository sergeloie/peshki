## 🧠 PROMPT ДЛЯ АГЕНТА (копируй целиком)

Ты — senior game UI/UX + rendering engineer + technical artist.
Твоя задача — **полностью переработать визуальный стиль браузерной игры (JS/TS)**, где персонажи (пешки) двигаются по круговому полю (как в Monopoly), сделав её **визуально премиальной, уютной и современной**, ориентируясь на стиль **Townscaper**.

---

# 1. 🎯 ЦЕЛЬ

Создать визуальный стиль, который:

* Выглядит как **живая игрушечная диорама**
* Максимально **приятен, мягок и расслабляющ**
* Вызывает эффект *“хочу рассматривать”*
* Убирает ощущение “веб-игры” → делает ощущение **инди-игры уровня Steam**

---

# 2. 🎨 ОБЩАЯ СТИЛИСТИКА

## Основные принципы (ОБЯЗАТЕЛЬНО)

* Мягкие формы (никаких острых углов)
* Скругления везде (8–24px+)
* Пастельная палитра
* Минимум текстур → максимум цвета
* Лёгкий “игрушечный” стиль
* Чистота и простота

## Вдохновение:

* Townscaper
* Diorama / toy world
* Handcrafted look
* Low-poly + soft shading

---

# 3. 🧩 ПЕРЕРАБОТКА КЛЮЧЕВЫХ ЭЛЕМЕНТОВ

## 3.1 Игровое поле (главное)

ЗАДАЧА: превратить скучное поле в **3D/2.5D мини-мир**

Сделать:

* Из плоского круга → **объёмная платформа**
* Добавить:

  * высоту
  * мягкие тени
  * ощущение “острова”
* Каждая клетка:

  * не просто квадрат → **мини-объект/здание/плитка**
  * слегка отличается по форме

💡 Идеи:

* Клетки = маленькие каменные плитки с промежутками между ними
* Поле = остров в воде, покрытый травой
* Добавить воду с лёгкой анимацией

---

## 3.2 Пешки (персонажи)

ЗАДАЧА: сделать их “живыми”

Из:

* примитивных фигур

В:

* маленьких персонажей / фигурок

Требования:

* округлые формы
* без сложных деталей
* яркие цвета
* лёгкая “пластиковость”

Добавить:

* анимацию броска костей, с визуализацией выпавших чисел, затенять ту кость, ход с которой был использован
* bounce-анимацию при движении
* маленькую тень под персонажем
* idle-анимацию (дыхание / покачивание)

---

## 3.3 Анимации

КРИТИЧЕСКИ ВАЖНО

Добавить:

* easing (ease-in-out, cubic)
* микродвижения
* плавность ВСЕГО

Примеры:

* движение пешки → не линейное, а “пружинящее”
* появление → scale + fade
* hover → лёгкое увеличение + тень

---

## 3.4 Свет и тени

Сделать:

* мягкие тени (box-shadow / fake 3D)
* глобальный “солнечный” свет
* лёгкий градиент освещения

Имитация:

* ambient occlusion
* мягкий directional light

---

## 3.5 Цветовая палитра

Использовать:

* пастельные оттенки
* ограниченную палитру (6–10 цветов)

Пример направлений:

* кремовый
* мягкий голубой
* тёплый жёлтый
* коралловый
* мятный

Избегать:

* чисто чёрного
* кислотных цветов
* резкого контраста

---

## 3.6 UI (интерфейс)

Переделать полностью:

### Кнопки:

* большие
* мягкие
* скруглённые
* с тенями
* добавить кнопку, для показа правил игры

### Панели:

* как “карточки”
* с лёгким blur (glass effect опционально)

### Шрифты:

* простой, дружелюбный
* без агрессии

---

## 3.7 Камера / перспектива

Если возможно:

Сделать:

* лёгкий **изометрический вид**
  ИЛИ
* псевдо-3D через тени и слои

Добавить:

* параллакс
* глубину сцены

---

# 4. ⚙️ ТЕХНИЧЕСКАЯ РЕАЛИЗАЦИЯ

## Обязательные технологии:

* CSS (shadows, gradients)
* Canvas или WebGL (если возможно)
* SVG для UI

## Если остаёмся в DOM:

* использовать:

  * box-shadow (много слоёв)
  * transform: translateZ / scale
  * filter: drop-shadow

---

## Псевдо-3D при отсутствии WebGL:

Использовать:

* layered shadows
* градиенты
* смещение по оси Y
* scale для глубины

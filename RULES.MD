# REAGENTS.MD — Правила игры "Пешки"

Документ для реализации логики игры в любом языке программирования.
Содержит полные, подробные и непротиворечивые правила.

---

## 1. Обзор игры

**"Пешки"** — настольная игра для 2-4 игроков на замкнутом поле.
Каждый игрок управляет 4 пешками, которые движутся по кольцу поля и должны попасть в домашнюю зону.
Цель игры — первым разместить все 4 пешки в доме и на углу.

**Основные механики:**
- Бросок 2 кубиков (значения 1-6)
- Движение пешек по кольцу и по дому
- Выставление новых пешек (при выпадении 6)
- Бой вражеских пешек (возвращение на скамью)
- Дополнительные ходы (при выпадении 6 или убийстве)

---

## 2. Поле

### Структура

Поле состоит из **кольца** и **домашних зон**.

#### Кольцо (Ring)
- **4 угла** (CORNER) — стартовые позиции игроков, конечные точки для победы
- **24 полевые клетки** (FIELD) — между углами
- Между каждыми двумя соседними углами ровно **6 полевых клеток**
- Движение по кольцу — **против часовой стрелки**

**Порядок углов:** Игрок 1 → Игрок 2 → Игрок 3 → Игрок 4 → Игрок 1 (замыкается)

#### Домашняя зона (Home)
- Линейный "хвост" из **3 клеток** (homeLength = numberOfPawns - 1 = 3)
- Ветвится от каждого угла вглубь
- Движение в доме — **только вперёд** (от угла к концу дома)

**Структура дома:**
```
Corner → Home_1 → Home_2 → Home_3 → null
```

### Координатная система

Поле — это **кольцевой связный список** через `nextFieldCell`, плюс **линейные ответвления** через `nextHomeCell` от каждого угла.

**Навигация:**
- `nextFieldCell` — следующая клетка кольца (против часовой стрелки)
- `nextHomeCell` — следующая клетка дома (от угла вглубь)

**Позиция на поле:**
- Позиция 0 = первая клетка после угла (corner.nextFieldCell)
- Позиция 23 = последняя клетка перед следующим углом

**Позиция в доме:**
- Позиция 0 = первая клетка за углом (corner.nextHomeCell)
- Позиция 2 = конец дома

## 3. Пешки

### Состояния пешки

| Состояние | Описание | Прогресс |
|-----------|----------|----------|
| **BENCH** | На скамье (не на поле) | -2 |
| **NEWBORN** | Только что вышла на поле (стоит на углу) | -1 |
| **FIELDER** | На поле (движется по кольцу) | 0-23 |
| **HOMER** | В домашней зоне | 1000 + позиция |

### Переходы между состояниями

```
BENCH → (выставить на угол) → NEWBORN → (первый ход с угла) → FIELDER → (войти в дом) → HOMER
  ↑                                                                         |
  +────────────────────── (снять с поля) ←──────────────────────────────────┘
```

### Нумерация пешек

- Пешки сортируются по прогрессу (чем выше — тем ближе к финишу)
- **#1** = самая близкая к финишу
- **#4** = самая далёкая

**Приоритеты (от высшего к низшему):**
1. HOMER (1000 + позиция) — чем дальше в доме, тем лучше
2. FIELDER (0-23) — чем ближе к углу, тем лучше
3. NEWBORN (-1)
4. BENCH (-2)

**Важно:** Нумерация пересчитывается после каждого хода.

## 4. Кубики

### Бросок
- **2 кубика**, значения от **1 до 6**
- Значения выпадают случайно

### Использование кубиков
- Можно использовать **каждый кубик по отдельности** (3 и 4 = ход на 3 + ход на 4)
- Можно использовать **сумму двух кубиков** (3 + 4 = ход на 7)
- **Нельзя** использовать один кубик дважды

### Примеры
```
Бросок: [3, 4]
Доступные ходы: 3, 4, 7 (3+4)

Бросок: [6, 6]
Доступные ходы: 6, 12 (6+6)
+ Выставление пешки (требуется 6)
```

## 5. Движение пешек

### Общие правила
- Пешка движется **против часовой стрелки** по кольцу
- Пешка в доме движется **только вперёд** по своей линии
- Нельзя **перепрыгивать** пешки на промежуточных клетках
- На **конечной клетке** нельзя встать на свою пешку (ход запрещён)
- На **конечной клетке** можно встать на вражескую пешку (бой)

### Детали движения

#### По кольцу (FIELDER/NEWBORN)
```
Для каждого шага i от 0 до steps-1:
  1. Взять следующую клетку кольца (getNextFieldCell)
  2. Если это угол игрока:
     - Если последняя пешка (3 другие в доме): 
       - Если i == steps-1: вернуть угол (победа!)
       - Иначе: вернуть null (перелёт запрещён)
     - Иначе: войти в дом (inHome = true, взять getNextHomeCell)
  3. Проверить промежуточную клетку:
     - Если i < steps-1 и клетка занята (любой пешкой): вернуть null
  4. Проверить конечную клетку:
     - Если i == steps-1 и клетка занята своей пешкой: вернуть null
```

#### По дому (HOMER)
```
Для каждого шага i от 0 до steps-1:
  1. Взять следующую клетку дома (getNextHomeCell)
  2. Если клетка null: вернуть null (конец дома)
  3. Проверить промежуточную клетку:
     - Если i < steps-1 и клетка занята: вернуть null
  4. Проверить конечную клетку:
     - Если i == steps-1 и клетка занята своей пешкой: вернуть null
```

### Переход из поля в дом

**Сценарий A: пешка стоит на своём углу (FIELDER)**
```
Пешка на Corner1 (свой угол), бросок = 3
  Шаг 0: current == corner → inHome = true, next = Corner1.nextHomeCell (= Home1_1)
  Шаг 1: next = Home1_1.nextHomeCell = Home1_2
  Шаг 2: next = Home1_2.nextHomeCell = Home1_3
  Результат: Home1_3
```

**Сценарий B: пешка кольцом подходит к углу**
```
Пешка на поле, 2 клетки до Corner1, бросок = 3
  Шаг 0: next = cellBeforeCorner.nextFieldCell (предпоследняя)
  Шаг 1: next = предпоследняя.nextFieldCell → Corner1
          Corner1 == corner → inHome = true
  Шаг 2: next = Corner1.nextHomeCell = Home1_1
  Результат: Home1_1
```

**Ключевой момент:** при входе в дом `getNextHomeCell()` вызывается **на том же шаге**, то есть пешка прыгает с угла сразу в первую клетку дома (Home1_1), не "стоя" на углу.

## 6. Правила боя

### Когда можно бить
- На **промежуточных клетках кольца** (FIELD)
- На **чужом углу** (CORNER)
- **Нельзя** бить в доме (HOMER)

### Что происходит при бое
1. Пешка попадает на клетку с вражеской пешкой
2. Вражеская пешка **удаляется с поля** и возвращается на **скамью** (BENCH)
3. Атакующая пешка занимает эту клетку

### Правила проверки боя
```
Если:
  - Пешка НЕ в доме (state != HOMER)
  - На целевой клетке есть пешка
  - Это ЧУЖАЯ пешка (pawn.player != this.player)
Тогда:
  - Вражеская пешка удаляется (remove())
  - Атакующая пешка перемещается на эту клетку
```

### Важные замечания
- Пешка **не может** бить, находясь в доме
- Пешка **не может** бить, находясь на скамье
- **Свою** пешку бить нельзя (ход запрещён)

## 7. Выставление пешки

### Требования
- Выпала **хотя бы одна 6** на кубике
- На углу игрока **нет своей пешки** (другие пешки мешают)
- Пешка берётся со **скамьи** (BENCH)

### Порядок действий
1. Проверить, что выпала 6
2. Проверить, что на углу нет своей пешки
3. Взять первую пешку со скамьи
4. Поставить её на свой угол в состояние **NEWBORN**

### Взаимодействие с вражеской пешкой
- Если на углу стоит **вражеская пешка** — она **снимается** (удаляется с поля, возвращается на скамью)
- Это считается **убийством** и даёт дополнительный ход

## 8. Цепочка ходов

### Порядок действий за один ход

1. **Бросок кубиков** — генерация 2 случайных значений (1-6)
2. **Выполнение ходов** — последовательное расходование кубиков:
   - Игрок (или бот) выбирает доступный ход
   - Выполняет его
   - Удаляет использованные кубики
   - Повторяет, пока есть кубики и доступные ходы
3. **Проверка дополнительного хода** — если:
   - Выпала **хотя бы одна 6**, ИЛИ
   - Была **сбита вражеская пешка**
   → Игрок получает **дополнительный ход** (снова бросает кубики)
4. **Смена игрока** — если не было дополнительного хода, ход переходит к следующему игроку

### Доступные ходы

#### Ходы одним кубиком
Для каждого кубика (3 и 4):
- Проверить каждую подвижную пешку (NEWBORN, FIELDER, HOMER)
- Если `findTargetCell(dieValue) != null` → ход доступен

#### Ходы суммой двух кубиков
Если выпали 3 и 4:
- Проверить каждую подвижную пешку
- Если `findTargetCell(3+4) != null` → ход на 7 доступен

#### Выставление с бенча (требуется 6)
Если выпала 6 и есть пешки на скамье:
- Проверить, что на углу нет своей пешки
- Доступен ход "выставить пешку"

#### Комбинация "выставить + двинуть" (PlaceAndMove)
Это **оптимизация для удобства игрока**. Технически это два действия:
1. Выставить пешку на угол (тратится 6)
2. Сразу двинуть эту пешку на другой кубик (тратится второй кубик)

**Пример:** Выпало 6 и 2. Угол доступен. Доступен ход "выставить пешку и сходить на 2".

**Правило:** Команда PlaceAndMove доступна только если:
- Выпала 6
- На углу нет своей пешки
- Путь от угла на значение второго кубика свободен

### Цепочка ходов бота

Бот выполняет **все доступные ходы за один ход**:
1. Бросает кубики
2. Пока есть кубики:
   - Генерирует все доступные ходы
   - Выбирает лучший (по стратегии)
   - Выполняет его
   - Удаляет использованные кубики
   - Проверяет, не победил ли
3. Если было убийство — получает дополнительный ход

## 9. Правило победы

### Условие победы
Игрок побеждает, когда:
1. **3 из 4 пешек** находятся в доме (state = HOMER)
2. **Последняя пешка** (4-я) **точно стоит на своём углу** (state = FIELDER, cell = corner)

### Правило последней пешки

Когда 3 пешки в доме, 4-я — последняя на поле.

**Особые правила для последней пешки:**
- Последняя пешка **НЕ заходит в дом** обычным порядком
- Она должна **ТОЧНО встать на свой угол**
- **Перелёт через угол запрещён** — если пешка "проскакивает" мимо угла, ход запрещён (findTargetCell возвращает null)

**Формулировка:** "Последняя пешка НЕ заходит в дом, а должна ТОЧНО встать на свой угол"

**Пример:**
```
Последняя пешка на расстоянии 7 клеток от угла
Бросок = 7 → Пешка точно встаёт на угол → ПОБЕДА!
Бросок = 8 → Пешка пролетает мимо угла → Ход запрещён
Бросок = 6 → Пешка не долетает до угла → Ход выполняется (пешка на позиции 6)
```

## 10. Ограничения

### Лимит ходов
- **5000 ходов** — защита от бесконечного цикла
- Если игра не завершена за 5000 ходов — ничья (или окончание по времени)

### Запреты
1. **Перелёт через угол** — запрещён (для последней пешки)
2. **Прыжки через пешки** — запрещены на промежуточных клетках
3. **Ход на свою пешку** — запрещён (на конечной клетке)
4. **Бой в доме** — запрещён (пешка HOMER не может бить)
5. **Выход с бенча без 6** — запрещён

## 11. Алгоритмы

### findTargetCell(steps, config)

**Вход:** пешка, количество шагов, конфигурация
**Выход:** целевая клетка или null (ход невозможен)

```
function findTargetCell(pawn, steps, config):
  current = pawn.cell
  corner = pawn.player.corner
  inHome = (pawn.state == HOMER)
  
  // Проверка: последняя ли пешка?
  isLastLapPawn = (NOT inHome) AND 
                  (count of HOMER pawns == numberOfPawns - 1)
  
  for i = 0 to steps-1:
    if NOT inHome:
      // Шаг по кольцу
      if current == corner AND pawn.state == FIELDER:
        // Стоит на своём углу — входим в дом
        if isLastLapPawn:
          return (i == steps-1) ? corner : null  // последняя: точное попадание
        else:
          inHome = true
          next = current.nextHomeCell
      else:
        next = current.nextFieldCell
        
        // Проверка перехода в дом
        if next == corner:
          if isLastLapPawn:
            return (i == steps-1) ? corner : null  // последняя: точное попадание
          else:
            inHome = true
    else:
      // Шаг по дому
      next = current.nextHomeCell
    
    // Проверки
    if next == null:
      return null  // выход за пределы
    
    if i < steps-1 AND next.pawn != null:
      return null  // промежуточная клетка занята
    
    if i == steps-1 AND next.pawn != null AND next.pawn.player == pawn.player:
      return null  // своя пешка на конечной клетке
    
    current = next
  
  return current
```

### generateAllMoves(player, dice, board, config)

**Вход:** игрок, кубики, доска, конфигурация
**Выход:** список доступных ходов

```
function generateAllMoves(player, dice, board, config):
  moves = []
  movablePawns = player.getMovablePawns()  // NEWBORN + FIELDER + HOMER
  
  // Ходы одним кубиком
  for each dieValue in dice:
    for each pawn in movablePawns:
      target = findTargetCell(pawn, dieValue, config)
      if target != null:
        moves.add(Move(pawn, dieValue, [dieValue]))
  
  // Ходы суммой двух кубиков
  if dice.size() == 2:
    sum = dice[0] + dice[1]
    for each pawn in movablePawns:
      target = findTargetCell(pawn, sum, config)
      if target != null:
        moves.add(Move(pawn, sum, [dice[0], dice[1]]))
  
  // Выставление с бенча (требуется 6)
  if dice.contains(6) AND player.hasBenchPawns():
    cornerCell = player.corner
    existingPawn = cornerCell.pawn
    
    if existingPawn == null OR existingPawn.player != player:
      moves.add(Move(null, 6, [6]))  // просто поставить пешку
      
      // Комбо: поставить + двинуть
      otherDice = dice без одной 6
      for each dieValue in otherDice:
        if canPlaceAndMove(player, dieValue, board, config):
          moves.add(Move(null, dieValue, [6, dieValue]))
  
  return moves
```

### canPlaceAndMove(player, steps, board, config)

**Вход:** игрок, шаги, доска, конфигурация
**Выход:** boolean (можно ли выставить и двинуть)

```
function canPlaceAndMove(player, steps, board, config):
  current = player.corner
  
  for i = 0 to steps-1:
    next = current.nextFieldCell
    
    if next == null:
      return false
    
    if i < steps-1 AND next.pawn != null:
      return false  // промежуточная клетка занята
    
    if i == steps-1 AND next.pawn != null AND next.pawn.player == player:
      return false  // своя пешка на конечной клетке
    
    current = next
  
  return true
```

### hasWon(player)

**Вход:** игрок
**Выход:** boolean (победил ли)

```
function hasWon(player):
  homeCount = count of player.pawns where state == HOMER
  
  if homeCount != numberOfPawns - 1:
    return false  // не все в доме
  
  lastPawn = first pawn where state != HOMER
  
  if lastPawn == null:
    return false
  
  if lastPawn.state == BENCH OR lastPawn.state == NEWBORN:
    return false
  
  return lastPawn.cell == player.corner  // точно на углу
```

### renumber(player)

**Вход:** игрок
**Выход:** обновлённые номера пешек

```
function renumber(player):
  // Вычислить прогресс для каждой пешки
  for each pawn in player.pawns:
    switch pawn.state:
      case HOMER:
        progress = 1000 + getHomePosition(pawn)
      case FIELDER:
        progress = getFieldPosition(pawn)
      case NEWBORN:
        progress = -1
      case BENCH:
        progress = -2
  
  // Сортировать по убыванию прогресса
  sorted = player.pawns.sortDescendingBy(progress)
  
  // Присвоить номера: #1 = ближе к финишу
  for i = 0 to sorted.length-1:
    sorted[i].number = i + 1
```

## 13. Примеры игровых ситуаций

### Пример 1: Обычный ход
```
Пешка игрока 1 на позиции 5 (FIELDER)
Бросок: [3, 4]
Доступные ходы:
  - На 3 клетки → позиция 8
  - На 4 клетки → позиция 9
  - На 7 клеток (3+4) → позиция 12
```

### Пример 2: Выставление пешки
```
Пешка на скамье (BENCH)
Бросок: [6, 2]
На углу нет своей пешки
Доступные ходы:
  - Выставить пешку на угол (NEWBORN)
  - Выставить пешку и сразу сходить на 2 (PlaceAndMove)
```

### Пример 3: Бой вражеской пешки
```
Пешка игрока 1 на позиции 5 (FIELDER)
Пешка игрока 2 на позиции 7 (FIELDER)
Бросок: 2
Результат:
  - Пешка игрока 1 перемещается на позицию 7
  - Пешка игрока 2 удаляется с поля (возвращается на скамью)
  - Игрок 1 получает дополнительный ход (было убийство)
```

### Пример 4: Последняя пешка (победа)
```
3 пешки игрока 1 в доме (HOMER)
Последняя пешка на позиции 17 (FIELDER)
Бросок: 7
Результат:
  - Пешка проходит 7 клеток и точно встаёт на угол
  - Игрок 1 побеждает!
```

### Пример 5: Последняя пешка (перелёт запрещён)
```
3 пешки игрока 1 в доме (HOMER)
Последняя пешка на позиции 17 (FIELDER)
Бросок: 8
Результат:
  - Пешка проскакивает мимо угла
  - Ход запрещён (findTargetCell возвращает null)
```

## 14. Важные замечания для реализации

### Ключевые инварианты
1. **Нумерация динамическая** — пересчитывается после каждого хода
2. **Победа = точное попадание на угол** — перелёт запрещён
3. **Нельзя прыгать через пешки** — на промежуточных клетках
4. **Extra turn** — при выпадении 6 ИЛИ убийстве
5. **Движок автономен** — не зависит от I/O

### Edge cases
| # | Ситуация | Поведение |
|---|----------|-----------|
| 1 | Пешка на промежуточной клетке, конечная занята своей | Ход запрещён |
| 2 | Пешка на промежуточной клетке, конечная занята вражеской | Ход разрешён (бой) |
| 3 | Пешка на промежуточной клетке, промежуточная занята | Ход запрещён |
| 4 | NEWBORN на углу, бросок = 1 | Переходит на поле (FIELDER) |
| 5 | HOMER в конце дома, бросок = 1 | Ход запрещён (конец дома) |
| 6 | Последняя пешка, бросок пролетает угол | Ход запрещён |
| 7 | Последняя пешка, бросок ровно на угол | Победа! |
| 8 | Пешка на чужом углу, бросок = 1 | Идёт по кольцу дальше |
| 9 | Бой вражеской пешки в доме | Запрещён (пешка HOMER не может бить) |
| 10 | Выход с бенча, угол занят своей пешкой | Невозможно |
| 11 | Выход с бенча, угол занят вражеской пешкой | Снимает вражескую пешку |
| 12 | Бросок [6, 6] | Два отдельных шеста, каждый может выставить пешку |
| 13 | Бросок [3, 4] | Ходы на 3, 4 и 7 |
| 14 | HOMER-пешка, findTargetCell | Двигается только по дому |
| 15 | NEWBORN на углу, переход в дом | Не входит в дом (идёт по кольцу) |
| 16 | Пешка на чужом углу, бросок = 1 | Идёт по кольцу |

### Тесты для проверки реализации
- `pawnStartsOnBench` — пешка начинает на скамье
- `pawnCanBePlacedOnCorner` — выставление на угол
- `moveToFieldTransitionsToFielder` — переход в FIELDER
- `moveToHomeTransitionsToHomer` — переход в HOMER
- `removeKicksPawnBackToBench` — снятие с поля
- `removeThrowsForHomer` — нельзя снять из дома
- `findTargetCellFieldMove` — движение по полю
- `findTargetCellBlockedByFriendlyPawn` — блокировка своей пешкой
- `findTargetCellCanLandOnEnemy` — бой вражеской пешки
- `findTargetCellNewbornMovesOnField` — NEWBORN идёт на поле
- `findTargetCellNewbornDoesNotEnterHome` — NEWBORN не входит в дом
- `findTargetCellHomerMovesInHome` — HOMER двигается по дому
- `findTargetCellOvershootHomeReturnsNull` — перелёт за конец дома
- `lastLapPawnWinsWithExactSteps` — победа последней пешки

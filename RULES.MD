# RULES.MD — Правила игры «Пешки»

Полная, однозначная спецификация логики игры.
Агент, реализующий игру **любом языке программирования**, должен получить
рабочую реализацию, следуя только этому документу.

> - Язык псевдокода — языко-независимый. Псевдокод нормативен: текст объясняет
>   «почему», псевдокод — «что именно делать».
> - Источник правды при сомнениях — поведение, описанное здесь. Раздел 16
>   (acceptance-критерии) — обязательный минимум тестов реализации.
> - Направление движения — **по часовой стрелке** (порядок углов 0→1→2→3
>   по периметру: верх → право → низ → лево).

## 0. Статус, охват, границы

### Статус

## 1. Обзор игры

**«Пешки»** — настольная игра для 2–4 игроков на замкнутом поле.
Каждый игрок управляет 4 пешками, которые движутся по кольцу поля
и должны попасть в домашнюю зону.
Цель — первым разместить все 4 пешки в доме, а последнюю — точно на свой угол.

**Основные механики:**
- Бросок 2 кубиков (значения 1–6).
- Движение пешек по кольцу и по дому.
- Выставление новых пешек (при выпадении 6).
- Бой вражеских пешек (возвращение на скамью).
- Дополнительные ходы (при выпадении 6 или убийстве).

---

## 2. Термины

| Термин | Значение |
|--------|----------|
| Угол (corner) | Стартовая клетка игрока на кольце; финишная клетка для победы |
| Поле (field) | Клетка кольца между углами |
| Дом (home) | Клетка домашней зоны игрока |
| Скамья (bench) | Вне поля; там ждут невыставленные и сбитые пешки |
| Кольцо (ring) | Замкнутая последовательность: углы + полевые клетки |
| Хвост дома | Линейная цепочка клеток дома от угла игрока вглубь |
| Шаг | Переход на одну клетку вдоль разрешённого направления |
| Сбитие (kill) | Снятие вражеской пешки (возврат на скамью) |
| Легальный ход | Ход, разрешённый всеми правилами этого документа |

## 3. Топология поля

### 3.1. Общее правило (параметрическое)

Топология привязана к количеству игроков `P` (допустимо 2–4):

- Поле — кольцо из `P` углов и `F` полевых клеток, где
  `F = P × (sideLength − 2)`.
- Углы стоят через равные промежутки: между соседними углами ровно
  `sideLength − 2` полевых клеток.
- Каждый угол `i` принадлежит игроку `i` (`0 ≤ i < P`).
- От каждого угла вглубь идёт хвост дома длиной `homeLength = numberOfPawns − 1`.
- Геометрия: 2 игрока — круг (углы на концах диаметра), 3 — треугольник,
  4 — квадрат. В общем случае — круг с углами через равные промежутки.

### 3.2. Стандартная конфигурация (P = 4, sideLength = 8)

- 4 угла + 24 полевые клетки = кольцо из 28 клеток.
- Хвост дома каждого игрока — 3 клетки.
- Всего клеток: 28 + 4×3 = 40.

### 3.3. Направление и порядок

- Движение по кольцу — **по часовой стрелке**: угол 0 → угол 1 → угол 2 →
  угол 3 → угол 0.
- Игроки ходят строго по возрастанию индекса: 0, 1, 2, 3, 0, …
- Движение в доме — только вперёд (от угла к концу хвоста).

### 3.4. Модель связей

Поле — ориентированный граф с двумя типами рёбер:

- `nextRing` — следующая клетка кольца (по часовой стрелке).
  У каждой клетки кольца ровно одно такое ребро; обход замыкается.
- `nextHome` — следующая клетка хвоста. Есть у каждого угла
  (ведёт в первую клетку дома) и у каждой клетки дома, кроме последней
  (у последней — отсутствует).

Позиция на кольце (для правил ниже) отсчитывается от собственного угла
игрока вперёд по `nextRing`. Позиция в доме — `0` (первая за углом) …
`homeLength − 1` (конец хвоста).

## 5. Пешки

### 5.1. Состояния

| Состояние | Где пешка | Условие |
|-----------|-----------|---------|
| BENCH | скамья | не на поле |
| NEWBORN | свой угол | выставлена, но ещё ни разу не ходила |
| FIELDER | кольцо (включая чужой угол и свой угол после ходьбы) | на поле, ходила, не в доме |
| HOMER | хвост своего дома | в доме |

### 5.2. Переходы

```
BENCH → (выставить) → NEWBORN → (сходить) → FIELDER → (войти в дом) → HOMER
  ↑                                                                          |
  └────────────────── (сбита, из любого состояния на поле) ──────────────────┘
```

Из дома сбить нельзя (§8.3), поэтому дуга «сбита» ведёт только
из NEWBORN/FIELDER.

### 5.3. Инварианты занятости (обязательные)

1. **Одна клетка — максимум одна пешка.** Состояние, где на клетке две
   пешки, недостижимо; реализация обязана его исключать.
2. Своя пешка блокирует: проход через клетку, остановку на ней,
   выставление на угол.
3. Вражеская пешка блокирует проход, но НЕ блокирует остановку:
   остановка на ней — бой (§8).
4. Индекс пешки (0 … numberOfPawns−1) стабилен всю партию: сбития
   и выставления меняют только позицию, никогда — порядок.

## 6. Кубики

### 6.1. Бросок
`numberOfDice` кубиков, каждый — целое от 1 до `numberOfSidesOnDice`
включительно, равномерно и независимо.

### 6.2. Использование значений
- Каждое выпавшее значение можно использовать **отдельным ходом**
  (бросок `[3, 4]` → ходы на 3 и на 4).
- При **ровно двух** кубиках additionally доступна их **сумма**
  (`[3, 4]` → ход на 7). При ином числе кубиков суммы нет.
- Каждый кубик расходуется не более одного раза: одиночка тратит свой
  кубик, сумма — оба, выставление — одну шестёрку (§9).

### 6.3. Комбинаторика и дедупликация (обязательно)
1. Сначала вычисляются **все** комбинации: каждый кубик × каждая подвижная
   пешка, плюс сумма × каждая подвижная пешка (если применимо), плюс
   выставления (§9).
2. Затем отбрасываются **полные дубликаты** — ходы с одинаковой тройкой
   (пешка, число шагов, набор потраченных кубиков).
3. Дедупликация — только для чистоты списка (особенно при одинаковых
   значениях, например `[6, 6]`): на правила расходования кубиков она
   не влияет.

Пример: `[6, 6]` даёт ходы на 6, на 6 (дубль отбрасывается) и на 12,
плюс выставления; каждая шестёрка может выставить отдельную пешку.

## 7. Поиск цели хода

Нормативный алгоритм. Вход: пешка, число шагов `S ≥ 1`.
Выход: целевая клетка либо `null` (ход невозможен).

```
function findTarget(pawn, S):
  current = pawn.cell
  corner  = pawn.player.corner
  inHome  = pawn.state == HOMER
  newborn = pawn.state == NEWBORN
  lastLap = (NOT inHome) AND (дом-пешек игрока == numberOfPawns − 1)

  for i = 0 .. S−1:
    last = (i == S − 1)

    if NOT inHome:
      if current == corner AND NOT newborn:
        // стоит на своём углу — уходит в дом
        if lastLap: return (last ? corner : null)
        inHome = true
        next = corner.nextHome            // первая клетка дома
      else:
        // шаг по кольцу (newborn с угла тоже идёт сюда)
        next = current.nextRing
        if next == corner:
          if lastLap: return (last ? corner : null)
          inHome = true                   // встанет на угол в этом шаге,
                                          // в дом — со следующего
    else:
      // шаг по дому; current может быть углом (только что встал на него)
      if current == corner:
        next = corner.nextHome
      else:
        step = homePosition(current)      // 0-based в хвосте
        if step + 1 >= homeLength: return null   // перелёт за конец дома
        next = homeCell(step + 1)

    occ = occupant(next)
    if (NOT last) AND occ != null: return null        // прыжки запрещены
    if last AND occ != null AND occ.player == pawn.player: return null
    current = next

  return current
```

Пояснения, обязательные к соблюдению:

- Сбитая/заблокированная промежуточная клетка запрещает весь ход,
  даже если цель свободна.
- Своя пешка на цели запрещает ход; вражеская — разрешает (бой).
- NEWBORN с угла всегда идёт по кольцу и никогда не входит в дом напрямую.
- FIELDER, стоящий на своём углу: 1 шаг ведёт в первую клетку дома
  (на углу «не стоит», а сразу уходит в дом).
- Подходящий по кольцу: шаг, приводящий на свой угол, ставит пешку
  НА угол; уход в дом — только со следующего шага.
- `lastLap` (все пешки кроме одной в доме): пешка обязана **точно**
  встать на угол; перелёт через угол запрещён (`null`), недолёт —
  обычный ход по кольцу.

## 8. Бой

### 8.1. Когда возможен
- Остановка FIELDER/NEWBORN-пешки на клетке с вражеской пешкой
  (поле кольца или чужой угол).
- Выставление на угол, занятый вражеской пешкой (§9.3).

### 8.2. Эффект
1. Вражеская пешка снимается с поля и возвращается на скамью (BENCH).
2. Атакующая пешка занимает клетку.
3. Сбитие даёт дополнительный ход (§10.3).

### 8.3. Запреты
- Пешка в доме (HOMER) не может ни бить, ни быть сбитой.
- Пешка на скамье не участвует в бое.
- Свою пешку сбить нельзя (такой ход просто запрещён).

---

## 9. Выставление пешки

### 9.1. Требования
- Среди выпавших значений есть 6.
- На углу игрока нет своей пешки (вражеская — допустима, см. §9.3).
- У игрока есть пешки на скамье.

### 9.2. Эффект
Первая пешка со скамьи ставится на свой угол в состояние NEWBORN.
Тратится одна шестёрка.

### 9.3. Выставление на вражеский угол
Вражеская пешка снимается (считается убийством → дополнительный ход),
своя ставится на угол.

### 9.4. PlaceAndMove (официальное правило с выбором)
Выставление и немедленный ход этой же пешкой — легальная пара:
1. «Только выставить»: тратится 6, остальные кубики остаются.
2. «Выставить + сходить»: тратится 6 и второй кубик; путь от угла
   на значение второго кубика проверяется тем же `findTarget`,
   но стартуя с угла и без входа в дом (newborn идёт по кольцу).
Игрок выбирает любой из доступных вариантов; оба предлагаются в списке ходов.

## 10. Цепочка ходов

### 10.1. Порядок действий за ход игрока
1. **Бросок** — `numberOfDice` значений.
2. **Расходование** — пока есть неистраченные кубики:
   - построить все легальные ходы (§10.2);
   - если список пуст — ход игрока закончен;
   - выбрать ход, выполнить, списать потраченные кубики;
   - проверить победу (§11) — при победе партия заканчивается немедленно.
3. **Дополнительный ход** (§10.3) или **смена игрока**.

### 10.2. Генерация всех ходов (нормативный алгоритм)

```
function generateAllMoves(player, dice):
  moves = []
  movable = пешки игрока в NEWBORN/FIELDER/HOMER

  // одиночные ходы (дедупликация одинаковых значений — §6.3)
  for each distinct value v in dice:
    for each pawn in movable:
      target = findTarget(pawn, v)
      if target != null: moves.add(ход пешкой на v, тратит [v])

  // сумма (только при ровно двух кубиках)
  if dice.size() == 2:
    sum = dice[0] + dice[1]
    for each pawn in movable:
      target = findTarget(pawn, sum)
      if target != null: moves.add(ход пешкой на sum, тратит оба)

  // выставления (требуется 6)
  if dice содержит 6 AND есть пешки на скамье:
    corner = угол игрока
    if на углу нет своей пешки:
      moves.add(выставить, тратит [6])
      for each второй кубик d (все кубики кроме одной 6):
        if путь от угла на d свободен (findTarget с угла, без входа в дом):
          moves.add(выставить + сходить на d, тратит [6, d])

  // отбросить полные дубликаты (§6.3)
  return deduplicate(moves)
```

### 10.3. Дополнительный ход
Игрок бросает кубики снова (тот же игрок ходит), если выполнено
**любое** условие — ровно один дополнительный ход, не два:

- выпала хотя бы одна 6 (даже если ходов не было — переброс);
- сбита хотя бы одна вражеская пешка.

### 10.4. Конец хода без продолжения
Переход к следующему игроку по возрастанию индекса (по кругу).

## 11. Победа и ничья

### 11.1. Победа
Игрок побеждает тогда и только тогда, когда одновременно:

1. Ровно `numberOfPawns − 1` его пешек — HOMER;
2. Последняя пешка — FIELDER, стоящий **точно** на его углу.

Проверка выполняется после каждого хода. Перелёт через угол победой
не считается (такой ход вообще запрещён, §7).

Следствие: если последняя пешка сбита на скамью, условие 1 нарушено —
особый режим снимается, игра продолжается по обычным правилам.

### 11.2. Ничья по лимиту
Если за `maxTurns` ходов (по умолчанию 10000) победитель не определился —
партия останавливается, фиксируется **ничья**, победителя нет.

## 12. Нумерация пешек для UI (только отображение)

> На механику не влияет. Домен не хранит номера и не меняет порядок
> ради отображения.

Метрика близости к дому (чем больше — тем ближе):

| Состояние | Прогресс |
|-----------|----------|
| BENCH | −2 |
| NEWBORN | −1 |
| FIELDER | пройденные шаги кольца от своего угла (0 … ringLength−1; стоящая на своём углу — максимум) |
| HOMER | 1000 + позиция в хвосте |

Номер `#1` — максимальный прогресс, далее по убыванию; равенство —
по меньшему индексу пешки (детерминированно). Пересчитывается
отображением при каждом показе, в движке не хранится.

## 13. Сводка инвариантов (контрольный список реализации)

1. Кольцо замкнуто; `nextRing` есть у каждой клетки кольца.
2. Одна клетка — максимум одна пешка.
3. Индекс пешки стабилен всю партию.
4. Прыжки через пешки запрещены; своя на цели запрещает; чужая на цели — бой.
5. NEWBORN с угла идёт только по кольцу.
6. FIELDER со своего угла уходит в дом за 1 шаг (не стоит на углу).
7. Последняя пешка: только точное попадание на угол; перелёт запрещён.
8. Бой только вне дома; сбитая возвращается на скамью.
9. Кубик тратится один раз; сумма — только при двух кубиках.
10. Доп. ход — один, при 6 или убийстве (даже вхолостую при 6).
11. Ходят по возрастанию индекса; движение — по часовой.
12. Победа — `numberOfPawns − 1` в доме + последняя точно на углу.
13. Лимит `maxTurns` — ничья без победителя.

## 14. Типовые ситуации (примеры)

```
1. Обычный ход:  пешка на кольце, бросок [3,4] → ходы на 3, 4 и 7.
2. Выставление:  скамья, бросок [6,2], угол свободен →
                 «выставить» и «выставить + на 2».
3. Бой:          враг на цели → встать, снять врага, доп. ход.
4. Победа:       3 в доме, последняя за 7 клеток до угла, бросок 7 →
                 точное вставание на угол, победа.
5. Перелёт:      та же позиция, бросок 8 → ход запрещён.
6. Вход в дом:   пешка на своём углу, бросок 3 → третья клетка дома.
7. Подход к дому: 2 клетки до угла, бросок 3 → первая клетка дома.
8. Конец дома:   HOMER у конца хвоста, шаг за предел → ход запрещён.
9. Занятый угол: свой на углу → выставление невозможно.
10. Чужой угол:  враг на моём углу, выпала 6 → снять врага, встать, доп. ход.
```

## 15. Задел на будущее (не норматив для P=4)

- P = 2: круг, углы на концах диаметра. P = 3: треугольник.
  Общее правило: углы через равные промежутки кольца.
- P = 5–6 потребуют не квадратной геометрии отображения,
  но кольцевая модель (§3.4) их уже поддерживает.
- Активных игроков всегда столько же, сколько углов: «спящие» углы
  запрещены (дают преимущество подсиживающему игроку).

## 16. Acceptance-критерии (обязательные тесты реализации)

Формат: given (дано) / when (действие) / then (ожидается).
Реализация считается верной, если проходит все пункты.

### Движение
1. given пешка FIELDER на кольце, when ход на N по свободному пути,
   then пешка смещается на N клеток по `nextRing`.
2. given путь занят на промежуточной клетке (любой пешкой),
   when ход через неё, then ход запрещён.
3. given своя пешка на цели, when ход туда, then ход запрещён.
4. given вражеская пешка на цели кольца, when ход туда,
   then своя встаёт, вражеская — на скамье, доп. ход.
5. given NEWBORN на углу, when ход на 1, then пешка на первой клетке
   кольца (FIELDER), не в доме.
6. given FIELDER на своём углу, when ход на 1, then пешка в первой
   клетке дома (HOMER).
7. given пешка за 2 клетки до своего угла, when ход на 3,
   then пешка в первой клетке дома.
8. given HOMER, when шагов больше, чем осталось до конца хвоста,
   then ход запрещён.
9. given HOMER, when ход внутри хвоста на свободные клетки,
   then пешка смещается, остаётся HOMER.

### Выставление
10. given скамья непуста, угол свободен от своих, when выпала 6,
    then доступны «выставить» и (при втором кубике и свободном пути)
    «выставить + сходить».
11. given своя пешка на углу, when выпала 6, then выставление недоступно.
12. given вражеская пешка на углу, when выставление,
    then вражеская — на скамье, своя — NEWBORN на углу, доп. ход.

### Кубики и очередь
13. given бросок [3,4], when генерация, then ходы на 3, 4 и 7, без дублей.
14. given бросок [6,6], when генерация,
    then ходы на 6 (без дублей) и на 12.
15. given выпала 6 и нет ходов, when очередь, then тот же игрок
    бросает снова.
16. given убийство без шестёрок, when очередь, then тот же игрок
    бросает снова (один доп. ход, не два при «6 + убийство»).

### Победа и ничья
17. given 3 HOMER + последняя за 7 клеток до угла, when ход на 7,
    then последняя точно на углу, победа.
18. given та же позиция, when ход на 8, then ход запрещён, победы нет.
19. given 3 HOMER + последняя недолетает, when ход,
    then обычный ход по кольцу, победы нет.
20. given победа достигнута, when проверка, then партия завершена
    немедленно, дальше ходы невозможны.
21. given maxTurns ходов без победы, when лимит достигнут,
    then ничья, победителя нет.
22. given последняя пешка сбита на скамью, when проверка,
    then режим «точного попадания» снят (условие 3-в-доме нарушено).

### Инварианты
23. given любая партия длины N, when аудит, then на каждой клетке ≤ 1
    пешки; индексы пешек не менялись; каждый кубик потрачен ≤ 1 раза.
